# Contributing to Talos

Thanks for your interest.

## Current scope

This repository currently contains documentation and repository scaffolding only.

Contributions should stay within that scope unless the repository contents change.

## Before opening a pull request

Please:

1. check for existing issues or pull requests
2. keep changes focused
3. avoid adding secrets, private references, or non-public material
4. update relevant documentation when contributor-facing behavior changes

## Repository expectations

Until additional public content is added:

- prefer simple, low-maintenance files and structure
- avoid adding dependencies or automation without a clear repository need
- keep changes understandable without private context

## Pull request guidance

- use clear commit messages and pull request descriptions
- describe what changed
- describe any verification performed
- do not include screenshots or attachments with private information

## Conduct and security

- Follow `CODE_OF_CONDUCT.md`.
- Do not report suspected security issues in public issues. Follow `SECURITY.md`.
